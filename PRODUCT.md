# TenseLab

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Learners who know English grammar rules and want to produce sentences more fluently. The supplied product architecture identifies A2–B1 as the initial audience.

## Product Purpose

Short daily practice of tense transformations and Russian-to-English translation, with self-assessment and local progress.

## Stack

React, TypeScript, Vite and MobX, explicitly approved by the user. Static hosting on GitHub Pages; no backend in this migration.

## Capabilities and Constraints

Preserve all twelve tenses, affirmative/negative/question forms, six pronouns, the existing verb bank, table drills, translation filters, retry queue, speech synthesis, keyboard controls, light/dark themes and local progress. The user requested separate app/demo storage and caches; legacy data remains intact in the old version. Keep the application usable offline after its first successful production load. Restructure sections while preserving the existing visual identity. Content corrections beyond migration are a separate task.

## Brand Commitments

Keep the TenseLab name, Russian interface, familiar light/dark design, violet accent and mint answer emphasis. The user delegated section organization and design refinements.

## Evidence on Hand

The incumbent HTML is preserved at old/index.html. It and docs/TenseLab_Product_Architecture_v0.1.docx describe the existing functionality and product direction. No learning-effectiveness claims have been validated. GitHub Pages serves the landing at /TenseLab/, main at /app/, develop at /demo/ and the original HTML at /old/.
